# Video Event Analytics Engine

A production-grade, browser-based Data Ingestion, Cleaning, Normalization, Validation, and Visualization Engine for AI Video Analytics JSON payloads.

---

## 🌟 Architecture Overview

This module is designed for processing raw, messy, or schema-inconsistent JSON payloads generated by computer vision inference systems (e.g. object detection, action recognition, motion tracking).

```
RAW JSON Payload (Pasted or Uploaded File)
         │
         ▼
┌─────────────────────────────────┐
│ 1. parseRawJSON()               │  → Safely parses JSON syntax
└─────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
│ 2. extractCandidateRecords()    │  → Recursively locates record arrays/objects
└─────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
│ 3. normalizeTimestamp()         │  → Converts "00:15", "1:10.5", 15.42s to seconds
└─────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
│ 4. normalizeEvent()             │  → Slugifies & formats event labels
└─────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
│ 5. validateRecords()            │  → Classifies into VALID, WARNING, or INVALID
└─────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
│ 6. deduplicateRecords()         │  → Detects duplicates while preserving evidence
└─────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
```

## 🚀 Key Features

### 1. Robust Data Ingestion
- **JSON File Upload**: Drag-and-drop or click to upload `.json` output files.
- **Raw Textarea Paste**: Paste raw JSON payload directly.
- **Preset Test Datasets**: Single-click loading of clean CV output and real-world messy JSON.

### 2. Data Cleaning & Normalization Engine
- **Flexible Field Resolution**: Automatically detects varied candidate keys for:
  - **Timestamps**: `timestamp`, `time`, `start_time`, `startTime`, `startTimestamp`, `frame_time`, `seconds`, `time_sec`, `elapsed_time`, `t`.
  - **Events**: `event`, `label`, `action`, `activity`, `description`, `class`, `event_type`, `eventType`, `type`, `name`.
  - **Confidence**: `confidence`, `score`, `prob`, `probability` (supports decimals e.g., `0.94` or percentages e.g., `"94%"`).
- **Time Normalization**: Handles `"00:15"`, `"00:01:20"`, `"1:10.5"`, `"15.42s"`, numbers, and floating-point seconds.
- **Event Label Cleaning**: Normalizes raw inputs like `"person_enter"`, `"Person Entered"`, `"PERSON ENTERED"`, and `"person-enter"` into standardized identifiers (`person_entered`) and formatted display labels (`Person Entered`).

### 3. Data Quality & Audit Summary
Computes real-time data health statistics directly from the ingested JSON:
- **Total Raw Records**
- **Valid Events**
- **Warnings Flagged**
- **Invalid Records Flagged**
- **Duplicates Detected & Flagged**
- **Unique Event Types**
- **Timestamp Boundary Range** (`Min` - `Max`)

### 4. Traceable Audit Table
- Complete filter controls by Search Term, Status (`Valid`, `Warning`, `Invalid`), and Event Type.
- Includes **"Inspect Raw"** action on every row to view the exact unaltered source JSON record and line index.

### 5. 3 Dynamic Visualizations (Derived Strictly from Normalized Data)
1. **Graph 1: Temporal Event Timeline**:
   - Scatter plot mapping exact event occurrences chronologically on the temporal axis.
   - Clickable point nodes that open the raw source record inspection modal.
2. **Graph 2: Event Type Distribution**:
   - Dynamic bar chart showing frequency counts per normalized event type.
3. **Graph 3: Activity Duration / Temporal Density**:
   - Displays exact activity durations in seconds when start/end interval bounds exist in the source data.
   - Automatically switches to point event occurrence density per 30-second video segment when only point timestamps exist (zero fabricated data).

## 💻 How to Run Locally

### Option 1: Direct Browser Access
Double-click `index.html` to open directly in any modern browser (Chrome, Firefox, Edge, Safari).

### Option 2: Local Server
```bash
# Using Node.js
npx serve .

# Using Python 3
python -m http.server 3000
```
Then visit `http://localhost:3000`.

## 🌐 How to Deploy

Because this repository contains pure client-side static assets (`.html`, `.css`, `.js`), it deploys instantly to any static host:
